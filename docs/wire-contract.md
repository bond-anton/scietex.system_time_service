# Wire contract

Frozen contract between `scietex.system_time_service`, the API domain
`system_time`, and the UI. Changing a field name here breaks a consumer.

## Service identity

Service name: `SystemTime`. Instance id is generated by the framework per
worker start.

## Config envelope

Key: `scietex:SystemTime:config`

The framework's `ConfigEnvelope` with a `services["system_time"]` section. The
API patches only these four fields; a three-state merge applies (absent = leave
alone, `null` = clear, value = set):

| Field | Type | Meaning |
|---|---|---|
| `timezone` | `str \| null` | IANA name; `null` means "leave the host alone" |
| `clock_source` | `"auto" \| "manual"` | `auto` = NTP, `manual` = operator sets the clock |
| `ntp_servers` | `list[str]` | NTP server hostnames |
| `rtc_in_local_tz` | `bool` | whether the RTC stores local time |

## Telemetry

Key: `scietex:SystemTime:{instance}:telemetry`, msgpack, published every 2 s
with a 6 s TTL. The struct omits `forbid_unknown_fields`, so a newer worker's
extra fields do not break an older reader.

```
SystemTimeTelemetry
  service: str
  instance_id: str
  clock: ClockStatus
  ntp: NtpStatus
  rtc: RtcStatus
  battery: BatteryStatus
  capabilities: Capabilities
  clock_source: str
  pending_apply: bool
  last_error: str | null
  timestamp: datetime
  schema_version: int = 1
```

### ClockStatus

```
local_time: datetime | null
utc_time: datetime | null
timezone: str | null
utc_offset_seconds: int | null
ntp_enabled: bool | null
ntp_synchronized: bool | null
rtc_in_local_tz: bool | null
```

### NtpStatus

```
daemon: "chrony" | "timesyncd" | "ntpd" | "none"
synchronized: bool
reference_id: str | null
stratum: int | null
system_offset_seconds: float | null
rms_offset_seconds: float | null
frequency_ppm: float | null
skew_ppm: float | null
root_delay_seconds: float | null
root_dispersion_seconds: float | null
leap_status: str | null
sources: list[NtpSource]
```

`NtpSource`: `name`, `state`, `stratum`, `reachability`, `offset_seconds`,
`jitter_seconds` — all optional except `name` and `state`.

### RtcStatus

```
present: bool
device: str | null
name: str | null
time_utc: datetime | null
since_epoch: int | null
drift_seconds: float | null
hctosys: bool | null
in_local_tz: bool | null
```

`drift_seconds` is RTC minus system clock, sampled at read time. sysfs gives
one-second resolution, so a healthy RTC reports a drift within ±1 s.

### BatteryStatus

```
available: bool
provider: "sysfs" | "command" | null
charge_percent: float | null
voltage_volts: float | null
status: str | null
detail: str | null
```

`available: false` means the hardware exposes nothing. It never means 0%.

### Capabilities

```
timedatectl: bool
timezone_settable: bool
clock_settable: bool
ntp_controllable: bool
ntp_configurable: bool
rtc_present: bool
battery_available: bool
privileged: bool
platform_id: str
ntp_daemon: str
```

The UI must gate every control on the matching capability. A control whose
capability is false is shown disabled with the reason, never hidden silently.

## Tasks

Control lane, submitted through the framework's task client.

| Task | Payload | Result |
|---|---|---|
| `system_time:status` | none | msgpack `SystemTimeTelemetry` |
| `system_time:read_rtc` | none | msgpack `RtcStatus` |
| `system_time:apply` | none | empty on success |
| `system_time:set_clock` | msgpack `{epoch_seconds: float, write_rtc: bool}` | empty on success |

### Error codes

| Code | Meaning |
|---|---|
| `PERMISSION_DENIED` | the worker is not root |
| `MISSING_BINARY` | a required binary is absent |
| `INVALID_TIMEZONE` | the IANA name is unknown |
| `NTP_UNAVAILABLE` | no controllable NTP daemon |
| `UNSUPPORTED_PLATFORM` | the platform has no supported NTP drop-in |
| `RTC_UNAVAILABLE` | no RTC on this host |
| `CLOCK_SOURCE_AUTO` | `set_clock` refused while `clock_source` is `auto` |
| `INVALID_PAYLOAD` | the task payload did not decode |
| `TIMEOUT` | the command timed out (retryable) |
| `DRY_RUN` | the mutation was recorded, not executed |
| `FAILED` | the command ran and failed |
